隱私權政策

最後更新：2026-10-30

適用對象

Mailcast 僅供開發者本人使用，不對外提供服務，也不收集任何其他使用者的資料。

存取的資料

  • Gmail（唯讀）：讀取本人信箱中的電子報內容，用於產生摘要。
  • Google Drive（僅限本應用建立的檔案）：上傳產生的語音檔。

資料使用與保存

資料僅用於上述用途，不會出售、分享或提供給任何第三方，也不用於廣告。產生的檔案只存放在本人的 Google Drive。

Mailcast 對 Google API 資料的使用遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

撤銷授權

可隨時在 Google 帳戶權限頁面 移除 Mailcast 的存取權。
